How do I export my calendar?
  • Google Calendar (computer): Settings → Import & export → Export. Unzip and pick the calendar's .ics file.
  • Outlook: Calendar → Share/Publish, or File → Save Calendar (desktop) as iCalendar.
  • Apple Calendar (Mac): select the calendar, then File → Export → Export….
  • Canvas or a class timetable: many offer an "iCal feed" or .ics download.

      How it works

      • The starter link holds the planning window in readable form after the #: dates, weekdays, daily hours, slot length and time zone. Browsers do not send the part after # to any server.
      • Each member's code holds only a display name, one bit per time slot (free or not), a 2-byte window check and a 2-byte checksum. A typo or a code cut off by a chat app is detected, not silently merged.
      • Calendar files are parsed in your browser with ical.js, including repeating events (RRULE, EXDATE and moved occurrences). You review the result before sharing.
      • Every slot is a fixed moment in time. Members in other time zones see the same slots labelled in their local time, including across daylight-saving changes.

      Privacy, and what it costs

      • This page is static files only. A Content Security Policy (connect-src 'none') stops the page from making any network request with your data, and the project's tests check this.
      • After the first visit it also works offline.
      • Trade-offs: someone has to collect the codes by hand; nothing updates live; and anyone who has a code can read that person's free/busy pattern for the window. Share codes only in the group's own chat.
